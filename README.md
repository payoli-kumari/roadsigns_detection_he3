# 🚦 Road Signs Detection – Machine Learning Module

This repository showcases my contribution to the **Road Signs Detection** project, where I worked as the **Machine Learning Model Trainer & Data Analyst**. My primary responsibility was to develop, train, evaluate, and optimize the object detection model used for recognizing road signs, along with analysing the dataset and model performance.

---

## 👨‍💻 My Role

**Machine Learning Model Trainer & Data Analyst**

As part of the project, I was responsible for the complete machine learning workflow, including data analysis, model training, evaluation, and performance optimization.

### Responsibilities

* Conducted **Exploratory Data Analysis (EDA)** on the road sign dataset.
* Analysed class distributions and dataset quality to identify potential issues such as class imbalance.
* Validated image annotations and prepared the dataset for model training.
* Configured and trained the object detection model using the **YOLO (You Only Look Once)** framework.
* Performed hyperparameter tuning to improve model accuracy and generalization.
* Evaluated model performance using industry-standard metrics, including:

  * Precision
  * Recall
  * F1-Score
  * Mean Average Precision (mAP)
* Analysed training results and compared multiple training experiments to select the best-performing model.
* Delivered the final trained model for integration into the application's frontend.
