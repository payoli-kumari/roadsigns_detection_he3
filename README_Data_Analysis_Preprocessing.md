# 🚦 Road Signs Detection — Data Analysis & Preparation

A data-focused contribution to a **Road Signs Detection** project, centered on finding, understanding, analysing, cleaning, and preparing the dataset for downstream computer vision tasks.

## 📌 Overview

This project focuses on the **data pipeline** required before model development. The work covers dataset exploration, quality checking, annotation validation, data cleaning, preprocessing, and preparation of structured data for further use.

The objective was to make the dataset **clean, consistent, well-organized, and ready for analysis and application development**.

## 🔍 Key Contributions

### 📂 Data Finding & Collection
- Identified and organized the required road-sign image dataset.
- Examined the available data and its structure.
- Checked the availability and organization of images and annotations.
- Reviewed dataset contents to understand the different road-sign categories.

### 📊 Exploratory Data Analysis (EDA)
- Performed exploratory analysis to understand the dataset.
- Analysed class/category distributions.
- Investigated the overall quality and consistency of the available data.
- Identified potential data-quality issues and inconsistencies.
- Used visual analysis to better understand the dataset.

### 🧹 Data Cleaning
- Checked image and annotation consistency.
- Identified missing, invalid, or problematic data where applicable.
- Verified that annotations corresponded correctly to the available images.
- Organized the dataset into a consistent structure.

### ⚙️ Data Preparation
- Prepared images and annotations for downstream computer vision workflows.
- Structured the dataset according to the required format.
- Verified that the prepared data could be used efficiently for further processing.
- Maintained a clean and organized dataset structure.

### 🔄 Data Preprocessing
- Performed the preprocessing required to make the raw dataset usable.
- Prepared image and annotation data in a consistent format.
- Applied appropriate preprocessing steps before downstream model/application integration.
